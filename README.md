# BibliotecaReservas - Sistema de Reservas de Biblioteca con Patrones de Diseño

Laboratorio práctico individual para el curso de Análisis y Diseño de Sistemas de Información / Ingeniería de Software II.
Implementación en consola utilizando Java 17 puro (sin librerías externas) de los patrones de diseño:
- **Builder**
- **Strategy**
- **Facade**
- **Observer**
- **State**

## Estructura del Proyecto
```text
BibliotecaReservas/
├── src/biblioteca/          # 21 clases de producción en paquete biblioteca
├── tests/biblioteca/        # Pruebas automatizadas P01 a P11 (Java estándar)
├── docs/                    # Documentación técnica, diagramas y reflexiones
├── evidencias/              # Guía de capturas y bitácora de auditoría
└── README.md
```

## Requisitos y Ejecución
- Java JDK 17 o superior.
- Git 2.40+.
